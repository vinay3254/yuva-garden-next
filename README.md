# Yuva Garden Group · Next.js Web App

A high-performance modern web application for **Yuva Garden Group** (Bettahalsur, Bangalore), built with Next.js (App Router), React, TypeScript, and Tailwind CSS.

## Features

- **Ambient WebGL Shader**: Fluid, subtle noise background reacting to mouse movement and scroll with Bangalore garden earthy hues (ivory, sage, wheat, moss).
- **Hero & Cinematic Scroll Zoom**: Smooth entrance animations with scroll-linked frame clipping and optical zoom effects.
- **Interactive Services Showcase**: 8 detailed landscaping and nursery services with hover/click preview and sticky image cross-fading.
- **Process Step Accordion**: "How we work" expandable columns for Visit, Design, Plant, and Care.
- **3D Tilt Nursery Cards**: Interactive perspective cursor response on cards.
- **Product & Service Catalog**:
  - Live category filtering (All, Plants, Services, Supplies)
  - Real-time search query filtering
  - Quick specs and care facts
  - Detail dialog modal with comprehensive specifications
  - **WhatsApp Cart / Order Tray**: Add items to your list and generate pre-filled WhatsApp quotes.
- **Bangalore Planting Seasons**: Seasonal guides (Monsoon, Winter, Summer) with curated plant recommendations.
- **Selected Work Carousel**: Horizontal project gallery with drag/touch physics.
- **Contact & Quote Generator**:
  - Dynamic store opening hours indicator (9 am – 7 pm)
  - Quick contact cards (Call, WhatsApp with photos, Maps navigation)
  - Interactive quote form building formatted WhatsApp messages
  - Interactive FAQ accordion
  - Bettahalsur Google Map embed

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

To create a production build:

```bash
npm run build
npm start
```
